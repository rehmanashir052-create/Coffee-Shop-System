About this prototype

This front-end prototype demonstrates the six modules defined in the project scope: POS order management, inventory, billing/payment records, employee management, customer loyalty/menu management, and reporting. It uses sample data in your browser session. A production version still needs the React/Node/Express backend, MySQL database, authentication and role-based permissions, server-side validation, secure backups, and proper testing.
