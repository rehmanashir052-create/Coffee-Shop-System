# Bean & Brew — Coffee Shop Management System

A responsive, browser-based front-end prototype for a Coffee Shop Management System (CSMS).

## Features
- Dashboard with sales statistics and recent orders
- Point of Sale (POS) cart, tax calculation, and sample checkout flow
- Inventory tracking and stock updates
- Order history and CSV export
- Employee roster and attendance controls
- Menu management and availability controls
- Reports and sales charts
- Responsive desktop and mobile layout

## Run locally
No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md` to the repository root, or push this folder using Git.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for deployment and open the URL shown in Settings → Pages.

## Project structure
```text
bean-and-brew-coffee-shop/
```

## Important note
This is a front-end demo. Sample data is held in page memory and resets on reload. It has no backend, database, secure authentication, or real payment processing. Add a backend and database before using it for real business operations.
